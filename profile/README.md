## ThinkerWave

An autonomous research agent for hard problems — the kind without a single right answer.
It works the problem round after round, checks its own work, and tells you which parts of
the answer are **verified**, which rest on an **assumption**, and which are a **guess**.

- **Use it:** [thinkerwave.ai](https://thinkerwave.ai) — in the browser, or the desktop app for Mac, Windows and Linux
- **Build with it:** [`thinkerwave`](https://github.com/thinkerwave-ai/thinkerwave) — Python SDK, `tw` command line, and an MCP server for Claude Code and Cursor

```bash
pip install thinkerwave
```
